#Real-Time Weather Forecasting System in C++

##Overview

This project is a back end simulation of **Real-Time Weather Forecasting System*& developed in C++. It fetches live weather data using an external API (**OpenWeather API**) and displays accurate weather information based on user input.
Unlike basic forecasting systems, this project integrates real-world data, making it more dynamic and practical.

##Features

* Fetch real-time weather data using API
* Display current temperature, humidity, and conditions
* User input-based location search
* Dynamic and up-to-date results
* Simple and interactive console interface

##Concepts Used

* API Integration
* File Handling (if used for storing data)
* Functions and Modular Programming
* Conditional Statements
* Input/Output Handling

##Technologies

* Language: C++
* API: OpenWeather API

##API Integration

This project uses a weather API to fetch real-time data.

###Example Workflow:

1. User enters city name
2. Program sends request to API
3. API returns weather data (JSON format)
4. Program parses and displays relevant information
